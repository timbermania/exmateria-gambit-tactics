## The recorded question, and why it did not block

Amendment 2 recorded a question: should the eighteen circled citations be rewritten to
name issue #229 (reading A), or should this ADR carry a mapping appendix (reading B)?

It did not block the fold, because the two readings **agree on the fact** — the glyphs
index #229's commit list — and disagree only on where the fix goes. A "states the now"
rewrite can state the fact and assert neither fix, which is what it does: the
Consequences record that `④c` is not `dec. 4`, give the correspondence that makes the
hazard concrete, and say the form is open at #687.

The one thing the fold had to be careful about is that **stating the mapping table inside
the ADR would itself have been choosing reading B.** So the table lives here, in the
audit note, which is not the document reading B is about:
