# ADR-0012 — audit notes

*Verified 2026-08-28. ADR-level verdict: `complete`. Produced by the de-amendment rewrite that folded this ADR's two addenda into the body.*

Every decision is built and re-measured against the tree, not against a citation. The roster order the ADR fixes — particle → sound → color (screen, palette) → camera — is exactly the array `EffectInstance` passes to `EffectTimeline.set_subsystems`, and `tests/EffectTimelineTest.gd` drives the pump with stub subsystems and asserts advance-order, the fixed-step accumulator, the open-phase set, null-skipping and reset.
Phase model C is `EffectPhase.open_phases` / `EffectPhase.dominant`; the three authored contexts are `phase1` / `for_each` / `phase2`, the same three `tools/parse_effect.py` emits.
"There is no manual mode" was re-derived today rather than trusted: `godot-learning/assets/effects/` holds 401 `E###` directories and all 401 carry a `timeline.json` — the ADR's 401-of-512 split, unchanged. `start_emitter` survives only in the comment at `src/effects/EffectInstance.gd` that records its removal; `timeline_enabled` is absent from the whole repo.
Two things moved after the ADR was accepted and the body now says so in the present tense rather than in an addendum: ADR-0014 supersedes the time-modulation split (coupling #1) and the "`EffectInstance` wires every output" rule, and issue #31 renamed the runtime `*TrackController` classes to `*Subsystem`.
Corrections made in the rewrite, each grep-proven: the `Subsystem` contract's third method is `is_done()`, not the `is_finished()` the ADR named (`is_finished()` is live in the tree but on `PhaseBlock` / `TrapPaletteController`, not on the contract); the sound adapter wraps `EffectSoundController`, not the retired `SoundTrackController`; `get_last_active_effect_frame` is on `ParticleSubsystem`; and the `"animate_tick"` string value the ADR argued to keep for ROM linkage was reversed on 2026-06-04 — `EffectPhase.PHASE_FOR_EACH` is `"for_each"`.

## Proposed guard arm

`EffectInstance` computes `has_timeline` and gates `EffectTimeline.start()` on it, but the ADR asks for a timeline-less-but-emitter-bearing effect to surface **loudly**; today that case is a silent no-start. The arm is a `push_warning`/`push_error` on `has_timeline == false` when the cast has emitter configs. Building it is `enforce-adr-conformance`'s job, not this pass's.
