## Numbering

**1–8 were already anchored** (`check_adr_anchors.anchors_of` flips `in_decision` on a `##`

`### Decisions` sat under `## Fourth amendment (…)` / `## Fifth amendment (…)` headings,
which do **not** match `decisions?\b`, so none of them published an anchor — the folded
decisions took 9–30 contiguously with no gap to preserve.
